# Domain documentation configuration

Single-context repository. Stable domain docs are GitHub Issues:
https://github.com/aaronx3011/agents-task-manager/issues/1
Setup, operations and client configuration:
https://github.com/aaronx3011/agents-task-manager/issues/3

Read that issue before changing models, readiness, lifecycle, authentication or API
contracts. Its Domain section is the glossary; Rules and decisions is the decision log.
Record new decisions there or in a linked documentation issue, with reasons.
Do not create local glossary/ADR/work-ticket files. Setup and operations are also
GitHub documentation issues. Project.docs_path can point to one of these issue URLs.
